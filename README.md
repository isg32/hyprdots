# hyprdots

Hyprland (Lua config) on Arch — dark, minimal, wallpaper-driven colors.

- **hypr** – config, hypridle/hyprlock, scripts (wallpaper carousel, screenshots, power modes), setup scripts
- **waybar**, **rofi**, **swaync** (Android-17 style notification panel), **alacritty**, **fastfetch**, **mpd + ncmpcpp**
- **matugen** – templates that recolor everything from the current wallpaper (accent: lime `#a8e063`)

Official Arch repo packages only (no AUR). Install: `bash hypr/setup/1-install-packages.sh`.
Wallpapers are not included — put yours in `~/Pictures/Wallpapers`, then `Super+W`.
